# Coffee EU-Check AI

Hệ thống AI hỗ trợ doanh nghiệp xuất khẩu nông sản đối soát pháp lý (Legal Compliance Checking).

Kiểm tra lô hàng có đáp ứng quy định của thị trường nhập khẩu (EU, USA, Japan, China) trước khi xuất khẩu hoặc sản xuất.

## Quy trình nghiệp vụ

1. **Pre-production** — Tuân thủ trước khi sản xuất
2. **Post-harvest** — Đánh giá sau thu hoạch

## Chạy本地

```bash
npm install
npm run dev
```

Truy cập `http://localhost:3000`
